# CombatePlus

Plugin de combate da rede, desenvolvido para Java 26 e Spigot 26.2.

## Sistema atual

Por enquanto o plugin possui apenas o sistema de cabeças:

- Chance configurável de dropar a cabeça de um jogador ao morrer.
- A cabeça do jogador mantém a skin da vítima.
- Cabeças de mobs e animais podem ser configuradas individualmente.
- Chance padrão e chance individual configuráveis.
- Material e nome das cabeças configuráveis.
- `/combateplus reload` para recarregar a configuração.

## Futuro

O sistema de combate será implementado posteriormente dentro do próprio CombatePlus.
